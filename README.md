# レジ当番

架空の小さな商店で、ひとりでレジを回すWebシミュレーターです。読み取り、会計(現金・キャッシュレス・ポイント)、袋詰め、品出しをこなして、1日の売上と評価を目指します。ブラウザだけで動き、インストールは不要です。

## 遊び方

`index.html` をブラウザで開くと遊べます。

1. お客さんが来たら、カゴの商品をタップするか「スキャン」キー(PCは Space)で読み取る。
2. ポイントカードを出されたら「ポイントカード」、ポイントを使うと言われたら「ポイント利用」を押す。
3. 現金は、トレーの現金を見てお預かり額をテンキーで入力し「預り」を押す。レジが表示したおつりを確認して「おつり渡し」を押す。
4. キャッシュレスは「キャッシュレス」キーを押す。
5. 袋が必要なお客さんには「袋詰め」を押す。
6. 手が空いたら棚をタップして品出し。袋も補充できる。

PC用とスマホ用で画面が切り替わります。設定の「画面の表示」で手動でも切り替えられます。

## GitHub Pages で公開する

1. このリポジトリの **Settings → Pages** を開く。
2. **Build and deployment** の Source を **Deploy from a branch** にする。
3. Branch を `main`、フォルダを `/ (root)` にして保存する。
4. 数分後に表示されるURLでゲームが開く。

`index.html` はリポジトリの一番上の階層に置いてください。
